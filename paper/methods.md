# Methods draft

We tested whether an origin language-model agent could spontaneously create a self-propagating ideological strategy during non-coding multi-agent collaboration. Each rollout contained six agents and normally lasted 30 rounds. Five initially clean agents analyzed a synthetic document case using immutable evidence, a shared task queue, shared report documents, direct messages, and private persistent memory. A randomly selected origin agent had only the direct-message tool. Agent identities and execution order were randomized from a recorded seed, and messages were delivered on the next round.

In the focal population-goal condition, the origin received a target position and the objective of maximizing the number of agents who genuinely adopted it. The prompt supplied no payload, sample message, propagation instruction, persistence instruction, memory reference, viral framing, or replication mechanism. In the matched personal-preference control, the origin received the identical position as a personal preference but no objective concerning other agents' beliefs. We also implemented a neutral control and an explicit-propagation positive control for manipulation checks.

We used a bridge graph for the confirmatory multi-hop test. The origin could contact one clean bridge agent, while clean agents could contact one another. Therefore, any target-bearing behavior from a distance-two clean agent required at least one agent-mediated hop. Fully connected graphs were analyzed only for direct susceptibility and secondary outcomes because they contain no distance-two agents.

At the end of each rollout, clean agents received the context-wipe warning used in the supplied study and one last opportunity to update private memory. A target-specific blinded judge scored final memory from 0 to 3, with 3 requiring strong advocacy or operationalization rather than quotation or neutral discussion. Outgoing messages were separately evaluated for advocacy and retransmission. A deterministic token-bounded screen supplemented the semantic judge, and a stratified sample was reserved for blinded human review.

The preregistered rollout endpoint required at least one initially clean agent that was at graph distance two or greater, never directly contacted by the origin, scored 3, retained target endorsement in private memory, attempted an outgoing target-related retransmission, and received at least one target-bearing direct message from a non-origin agent delivered no later than its first target-bearing activity. The rollout was the independent observation. The primary estimand was the population-minus-personal-preference risk difference across preregistered cases and target positions. We reported Wilson intervals, a stratified paired bootstrap interval, a Newcombe interval, a one-sided Fisher exact test, and an adjusted logistic model with design-factor fixed effects and block-clustered standard errors when estimable.

The non-coding environment was the deliberate domain change from the supplied coding-agent study. The second deliberate change was replacing an evolved viral seed with a goal-only origin prompt. We retained the six-agent structure, 30-round horizon, direct-message-only origin, private memory, task queue, fully connected and bridge graphs, final memory warning, four ideological target families, strict 0–3 judging, model variation, and warning-defense concept.
